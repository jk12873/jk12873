### 👨‍💻 Executive Summary

I am a **Software Development Engineer** with **4+ years of experience** specializing in high-throughput enterprise backend engineering, microservices architectures, and AI-driven workflow modernization. Currently at **Accenture**, I serve as a core backend engineer for the **Accenture Human Services Suite (AHSS)**—a mission-critical multi-tenant public assistance platform operating at state scale.

- ⚙️ **Core Engineering:** Enterprise-grade REST microservices using **Java (JDK 8 → 21 migration)**, **Spring Boot 3**, **Hibernate / JPA**, and asynchronous message-driven pipelines with **Apache Kafka**.
- 🚀 **High Concurrency & Tuning:** Deep mastery in multithreading, concurrent data structures, and relational query optimization across **Oracle 19c** and **MySQL**, cutting database latency by **25%** and boosting concurrency by **30%**.
- 🤖 **Applied GenAI & Automation:** Designing intelligent agentic workflows and document extraction pipelines with **Spring AI**, **OpenAI API**, and structured prompt engineering for automated case eligibility and caseworker assistance.
- 🏛️ **Architecture & Standards:** Strong advocate for clean architecture, SOLID principles, design patterns, automated CI/CD pipelines, and web accessibility (**WCAG 2.1 compliance champion**).

### 💼 Career & Enterprise Highlights

#### **Accenture** — *Software Development Engineer* `[12/2022 – Present]`
> **Core Contributor to Accenture Human Services Suite (AHSS)** — Enterprise SaaS platform delivering public assistance & healthcare benefits for millions of recipients across U.S. state health & human service departments.

* **High-Throughput Microservices:** Architected and shipped mission-critical Java 21 & Spring Boot RESTful services and Angular UI components, standardizing on robust design patterns, thread-safe concurrency models, and resilient error recovery.
* **Concurrency & Latency Optimization:** Refactored critical batch and transaction workflows using concurrent collections, non-blocking operations, and pool tuning—driving a **30% improvement in concurrency processing** under peak transaction windows.
* **Database & Query Engineering:** Optimized enterprise schemas and tuned complex queries across **Oracle 19c** and **MySQL**, achieving a **25% reduction in execution latency** across high-frequency audit and eligibility tables.
* **JDK 8 → JDK 21 Migration:** Led codebase modernizations eliminating technical debt, refactoring legacy patterns to modern Java idiom (records, pattern matching, virtual threads readiness), and delivering **200+ feature enhancements and fixes**.
* **GenAI-Powered Public Services Modernization:**
  * Engineered GenAI-integrated microservices utilizing **Spring AI**, **Kafka**, and **OpenAI APIs** to automate case eligibility evaluations and unstructured document ingestion.
  * Implemented structured document intelligence pipelines extracting data from complex citizen applications into verified relational models.
  * Built context-aware caseworker assistants offering automated case summarization and knowledge retrieval, drastically cutting manual review bottlenecks.
* **Enterprise Accessibility Leadership:** Championed and executed the project-wide **WCAG 2.1 AA** compliance initiative, earning company-level recognition for inclusive software engineering.
